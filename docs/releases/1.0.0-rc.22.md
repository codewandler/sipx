# sipx 1.0.0-rc.22

This candidate closes five stories across application control, registrar lifecycle, diagnostics,
SDK documentation and test-only media tooling. It follows the published rc.21 boundary; none of
the work here is carried from an unpublished candidate.

Stable promotion remains deliberately out of scope. It still requires use by an application nobody
in this repository wrote.

## Install

```sh
cargo add sipx-call@=1.0.0-rc.22
cargo install --locked --version '=1.0.0-rc.22' sipx-cli
```

## Five-story release wave

- The application wire contract now carries desired-state `dsp_bypass`. A requested bypass and
  restore produce correlated terminal events at the graph's sample boundary, while stale or foreign
  graph state, supervised stages and runtime-imposed bypasses remain typed, non-mutating refusals.
- Registrar discovery sends its in-dialog cancellation through endpoint admission before command
  exit. The barrier is intentionally local: it does not turn an unanswered cancellation into a wait
  for a response, terminal NOTIFY or Timer N, and shutdown joins the remaining owned tasks.
- `sipx-app` joins the diagnostic checker’s at-rest scope. Public WebSocket messages report their
  variant and byte length while withholding text and binary call content; behavioral tests likewise
  hold the host's credential-bearing carriers to bounded records.
- The SDK contract page carries an exact generated inventory of the normative event table. A sync
  failure names each event absent from the page, so a new family cannot disappear behind a generic
  generated-content mismatch.
- The supervised worker-protocol harness vocabulary, generator, oracle, replay tests, example and
  corpus live in `sipx-testkit`. The media crate exposes only one hidden opaque bridge to its private
  runtime, and a fresh CI-budget campaign completed 151,127 executions in 61 seconds at 2,477 per
  second with no finding.

## Verification boundary

The candidate gate covers the workspace feature matrix and all features together, release-package
rehearsal, RFC corpus recovery, the relocated worker corpus integrity check, public-page generation,
diagnostic-surface checks, one non-Linux cross build and both WebAssembly targets. Publication is
still bound to the reviewed annotated tag, exact-SHA CI and Pages evidence, an exact registry
consumer, portable CLI artifacts and a prerelease record.
