# sipx 1.0.0-beta.1

> **Superseded historical prerelease. Use
> [1.0.0-beta.2](https://github.com/codewandler/sipx/releases/tag/v1.0.0-beta.2).**

This immutable beta.1 candidate was distributed after beta.2 to complete its protected release
record. Its original workflow run stopped at the mandatory provenance gate before package
rehearsal, any registry write, consumer verification, Pages proof or GitHub Release. The tag was
never moved; the replay reran those proofs against the original source and package bytes.

The package set is usable, but beta.2 is the current and recommended prerelease:

```bash
cargo add sipx-call@=1.0.0-beta.2
```

Beta.1 contains a public dispatcher example that detaches a task and calls `expect`. Those patterns
contradict sipx's bounded-ownership and no-panic working agreement; `X-70` corrected the example in
beta.2. The library and CLI capability surface is otherwise the candidate described by this tag,
but new adoption should not select the older version.

For historical verification, all eleven exact beta.1 packages were produced from annotated tag
`v1.0.0-beta.1`, checked through an exact registry consumer and an installed Opus CLI loopback, and
matched to the archived documentation artifact built from the same commit. This record posts no
broader announcement.
