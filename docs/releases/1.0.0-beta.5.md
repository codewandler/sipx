# sipx 1.0.0-beta.5

sipx `1.0.0-beta.5` is an endpoint-services and application-integration prerelease. It carries the
complete post-beta.4 endpoint wave, publishes deterministic downstream test support, records one
bounded signalling-load result, and adds a routed G.711 bridge to realtime audio agents.

Pin the exact Rust crates while the API remains pre-1.0:

```bash
cargo add sipx-call@=1.0.0-beta.5
```

Install the diagnostic phone from crates.io:

```bash
cargo install sipx-cli \
  --registry crates-io \
  --version '=1.0.0-beta.5' \
  --locked
```

The named browser-audio profile remains optional and needs both native media features:

```bash
cargo install sipx-cli \
  --registry crates-io \
  --version '=1.0.0-beta.5' \
  --locked \
  --features opus,dtls
```

## What changed since beta.4

- **Live endpoints gained explicit operational control.** Applications can rotate the certificate
  identity used by new TLS handshakes, observe parsed traffic and connection transitions through a
  bounded stream, install immutable request-header policy, and update a bounded source-admission
  set without disturbing established calls.
- **SIP event services now run in both roles.** The live dispatcher can serve subscriptions and
  conditional publications; public clients authenticate, refresh, unsubscribe and drain their
  timers and transactions. Registration discovery exposes current registrar contacts to `sipx
  peers`, and registration success reports the address observed in the response without turning
  that diagnostic into routing or media policy.
- **Applications can own more dialog state.** Confirmed quiescent dialogs have a bounded versioned
  snapshot and restoration boundary. Inside a live dialog, INFO, MESSAGE and explicitly admitted
  private methods can be delivered to application policy without transferring transaction cleanup
  or response ownership out of the call runtime.
- **Downstream tests no longer need private fixtures.** `sipx-testkit` is a public package with a
  socket-free call harness, virtual time, seeded in-process links, a finite RTP/PCMU echo peer and a
  deterministic realtime peer. The release rehearsal compiles the archived echo example against
  the complete staged public dependency closure before any registry write.
- **Operations have bounded executable evidence.** Libraries remain quiet until the embedding
  process installs a tracing subscriber. The CLI adds a finite signalling responder with explicit
  admission, concurrency, lifetime and cleanup bounds. The published comparison includes one
  reproducible UDP dialog-signalling run with raw hashed repetitions, median and spread, and
  post-drain zero-state evidence; it is not a general performance ranking.
- **A routed call can terminate on a realtime audio agent.** `sipx-host` can bind one routed G.711
  call to one authenticated realtime WebSocket session. Encoded PCMU or PCMA frames cross in both
  directions without transcoding; queues are bounded with counted loss, barge-in flushes pending
  output, failures are typed, and all tasks are joined before the terminal report. The general
  non-SIP secure-WebSocket client uses the same certificate policy as SIP transports and refuses
  credentials embedded in URLs.

## Migration and stability

This wave is additive for Supported beta.4 APIs: existing call constructors, ordinary media
profiles, transport defaults and CLI commands keep their previous behavior. Adopt new endpoint
policy, event, persistence, testkit or realtime surfaces explicitly. The subscription store and
built-in dialog, registration and presence package documents are now Supported because the shipped
call application reaches them; future breaking changes to those surfaces receive migration notes.
The higher-level event runtimes and the language-neutral host wire contract remain Experimental.

Public APIs are not frozen before stable 1.0. Supported APIs may still change with changelog and
migration guidance; Experimental APIs may change or be removed without that guide.

## Intentional limits

- **Realtime live-endpoint proof:** the default suite proves the complete bridge against a
  deterministic peer and through a real SIP/RTP call. The opt-in credentialed interoperability
  proof against the live service has not yet been recorded.
- **Realtime scope:** one call maps to one session, G.711 is passed through, and the bridge does not
  originate calls, transcribe, choose tools or retain a conversation service.
- **Comparative load scope:** the published result covers one bounded UDP responder direction on one
  recorded host. Secure transports, connection churn, media, other call rates and an overall winner
  are not measured.
- **Browser boundary:** TURN-required networks, video, data channels, browser-facing application
  APIs and a general browser media engine remain outside the release.
- **Product roles:** proxy, registrar, PBX, routing-product and dial-plan roles remain outside this
  endpoint library.
- **Stable compatibility:** `1.0.0-beta.5` is a prerelease, not an API freeze.

Every public package is produced from one immutable annotated tag, verified from exact registry
versions, exercised through an installed Opus CLI, and checked against documentation deployed from
the same commit. This repository prerelease is not a broader announcement.
