# sipx 1.0.0-beta.1

sipx is now available as modular Rust crates for building SIP and VoIP systems: sans-I/O SIP and
SDP cores, transport and user-agent layers, RTP/media, call control, and application hosting.

```bash
cargo add sipx-call@=1.0.0-beta.1
```

The `sipx` diagnostic phone is the executable proof of those layers. Release verification installed
its exact registry package with optional Opus support and completed a bounded loopback call:

```bash
cargo install sipx-cli \
  --registry crates-io \
  --version '=1.0.0-beta.1' \
  --locked \
  --features opus

sipx version
```

The beta includes placing, answering and registering calls; UDP, TCP, TLS, WebSocket and secure
WebSocket signalling; G.711 and optional Opus audio; RTP/RTCP, ICE and SRTP; interactive scenarios,
bounded load, live-device support, and webhook or session-driven application hosting.

This is a prerelease, not an API freeze. Supported APIs may still break before 1.0 with changelog
entries and migration guidance. Experimental APIs may change or be removed without a migration
note.

Intentional omissions include proxy, registrar, PBX, routing and dial-plan products; TURN relay;
video and a complete browser-media stack; arbitrary application codecs; a graphical phone and
headset mixer; automatic live-state presence and SIP messaging; and packaged embedded, subprocess
or TypeScript application bindings. SIP over QUIC and the language-neutral application wire
contract remain Experimental.

All public packages were produced from one immutable annotated tag, verified from exact registry
versions, and checked against the documentation deployed from the same commit.
