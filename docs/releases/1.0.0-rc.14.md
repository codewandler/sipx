# sipx 1.0.0-rc.14

Six stories. The extensibility rollout is finished across every published crate while the choice is
still reversible, applications can read what voice detection is measuring against, and three
repository checkers stopped accepting what they could not see. A prerelease on the same terms as its
predecessors: stable promotion still requires use by an application nobody in this repository wrote.

## Install

```sh
cargo add sipx-call@=1.0.0-rc.14
cargo install --locked --version '=1.0.0-rc.14' sipx-cli
```

## Migration — read this one

**Every reachable public enum in `sipx-sip`, `sipx-transport`, `sipx-ua`, `sipx-app` and
`sipx-testkit` is now `#[non_exhaustive]` or carries a written argument for being exhaustive.** This
completes the rollout `M-74` began on the media path and retires the checker's crate boundary, so a
new crate is covered by existing rather than by being added to a list.

A downstream `match` on one of the 61 marked types — `Method`, `Scheme`, `UriTransport`,
`TransportKind`, the transaction `Output` and `TuEvent`, and the event and publication client
vocabularies among them — needs a `_` arm it did not need before. What it buys is that sipx can add
a method, a transport or a driver instruction in a **minor** release instead of a major one. Taken
now on purpose: the attribute can be removed in a minor release and only added in a major one, so
this is among the last candidates in which the choice can still be made.

One behavioural consequence, deliberate: three transport conversions now return `Option`, and their
callers decline to send rather than approximate, because every total fallback downgrades a protected
flow.

## Added

**Applications on the `sipx.app.v1` contract can read what a call's voice-activity detection is
measuring against**, as the call snapshot's `voice` member, and are told when calibration moves it
by the new `call.voice.thresholds` event. Every field is a sample count or an amplitude. The wire
carries no audio, and the record has no field that could hold a sample sequence — enforced by the
type, by a serialization test that refuses any non-numeric member, and by holding the member set
against the spec's own table.

**`capacity_test` and `load_test` gain `--media none`**, a mode that negotiates no session on either
end, so plain SIP throughput can be measured apart from the cost of having a media stack. The caller
half is now public in `sipx-call` as `dial_signalling` and shared with `sipx load --mode signalling`,
which was rewritten onto it rather than keeping a second copy.

## Fixed

**Three checkers stopped accepting what they could not see.** One command's `--help` may name
another command's flag again; a flag list broken by prose is reported rather than silently accepted;
and the audio-claims guard reads the whole preamble of an item at the top of a file. Each fix also
pins the opposite direction — a reader that sees nothing reports everything as missing rather than
going quiet.

**The generated-media load-pair test has admission headroom.** Its `connected == calls` is now a
claim about the workload rather than about whether the responder's accept loop was scheduled before
the replacement INVITE arrived.

## Intentional limits

- sipx is a programmable user-agent stack and diagnostic phone — not a proxy, registrar, PBX,
  routing product or general browser-media engine. Video is not admitted.
- **No speech implementation and no DSP processor ships** behind their contracts.
- **AEAD interoperation is proven for `AEAD_AES_256_GCM` over DTLS only.**
- **The browser binding has no run against a real WSS endpoint.**
- **The three-way media comparison is not recorded.** `--media none` ships without the measurement
  it exists to enable: every box available while this candidate was cut was building something else,
  and a ramp taken under that load reports the machine's ceiling rather than sipx's.
- **`docs/measurements/` is not deployment sizing.** Both ends share one process and one scheduler.
- **No independent production application or third-party security audit is recorded.**
