# sipx 1.0.0-beta.3

sipx `1.0.0-beta.3` is the current prerelease built from the latest `main`. It keeps the beta.2
library and diagnostic-phone behavior while shipping the repository's newer measured adoption and
release surfaces.

```bash
cargo add sipx-call@=1.0.0-beta.3
```

What changed since beta.2:

- A generated public comparison now evaluates sipx across language safety, transport, media,
  security posture, conformance evidence, and project maturity. Every cell carries its evidence
  class, sipx's own values are computed from the tree, and stale observations fail the gate.
- Interrupted crates.io publication has a protected, checksum-bound recovery path. It reproduces
  visible archives from the immutable tag before advancing only the next dependency-ready frontier.
- The roadmap records demand-led audio, transport, interoperability, packaging and observability
  epics as explicit future work. Those stories are not claims that the runtime features already
  exist.

The `sipx` diagnostic phone remains the executable proof of the released crates:

```bash
cargo install sipx-cli \
  --registry crates-io \
  --version '=1.0.0-beta.3' \
  --locked \
  --features opus

sipx version
```

The shipped endpoint surface includes placing, answering and registering calls; UDP, TCP, TLS,
WebSocket and secure WebSocket signalling; G.711 and optional Opus audio; RTP/RTCP, ICE and SRTP;
interactive scenarios, bounded load, live-device support, and webhook or session-driven
application hosting.

This is a prerelease, not an API freeze. Supported APIs may still break before 1.0 with changelog
entries and migration guidance. Experimental APIs may change or be removed without a migration
note.

Intentional omissions include proxy, registrar, PBX, routing and dial-plan products; TURN relay;
video and a complete browser-media stack; arbitrary application codecs; a graphical phone and
headset mixer; automatic live-state presence and SIP messaging; and packaged embedded, subprocess
or TypeScript application bindings. SIP over QUIC and the language-neutral application wire
contract remain Experimental.

All public packages are produced from one immutable annotated tag, verified from exact registry
versions, exercised through an installed Opus CLI, and checked against documentation deployed from
the same commit. This repository prerelease is not a broader announcement.
