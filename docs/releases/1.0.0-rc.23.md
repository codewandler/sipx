# sipx 1.0.0-rc.23

This candidate closes five stories across call negotiation, live media composition, deployment
diagnostics, cluster resolution and release pacing. It follows the published rc.22 boundary; none
of the work here is carried from an unpublished candidate.

Stable promotion remains deliberately out of scope. It still requires use by an application nobody
in this repository wrote.

## Install

```sh
cargo add sipx-call@=1.0.0-rc.23
cargo install --locked --version '=1.0.0-rc.23' sipx-cli
```

## Five-story release wave

- Incoming offerless calls can put their offer in the successful final response and settle the
  answer from ACK. Invalid answers tear the confirmed dialog down, and the off-media two-dialog
  owner relays the same shape without binding media or waiting through the full transaction
  lifetime for a missing source ACK.
- A bridge or conference membership now follows the call's replacement media generation. The new
  session is connected before the retired one is cleared, so renegotiation preserves audio,
  keypress behavior, participant identity and truthful connection state.
- Outbound settlement rejects an advertised private address that overlaps the private realm implied
  by the peer's negotiated media address, unless the operator explicitly allows it. The command
  reports a separate signalling/media interface split and closes the established dialog cleanly.
- Exact namespaced cluster service names receive a bounded EndpointSlice lookup only after ordinary
  SIP DNS yields no candidate. The single authenticated HTTPS request admits ready addresses into
  the existing ordered candidate walker; short names, explicit next hops and successful DNS remain
  untouched.
- Publication pacing now survives the release helper's frontier process boundaries. Both allowance
  buckets use a shared wall-clock model, carry stated retry deadlines and charge attempts before
  dispatch, while registry visibility and checksums remain the only publication evidence.

## Verification boundary

The candidate gate covers the workspace feature matrix and all features together, release-package
rehearsal, RFC corpus recovery, generated public documentation, diagnostic-surface checks, one
non-Linux cross build and both WebAssembly targets. Publication remains bound to the reviewed
annotated tag, exact-SHA CI and Pages evidence, an exact registry consumer, portable CLI artifacts
and a prerelease record.
