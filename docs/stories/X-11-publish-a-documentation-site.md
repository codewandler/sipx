# Publish a documentation site

## Goal
Somewhere to send someone who wants to use sipx and is not going to read a Rust workspace to
find out how.

## Acceptance
- [ ] A static site at `codewandler.github.io/sipx`, built from `docs/` rather than written
      twice — a second copy of the truth is a second copy to let rot.
- [ ] Published by CI on push to `main`, not by hand.
- [ ] The compliance table and the RFC roadmap are pages on it, generated by the same script
      that checks them.
- [ ] The landing page answers "what is this and can it do what I need" above the fold, without
      a command in sight.
- [ ] The README links to it, and it links back to the source.
- [ ] Builds are reproducible locally with one command, so a change can be seen before it ships.

## Progress
- Not started.

## Notes
- The constraint that shapes it: an end user is not going to type a lot of commands. The site
  is for deciding whether sipx fits, and for reference once it does — not a tutorial that
  assumes a terminal is already open.
