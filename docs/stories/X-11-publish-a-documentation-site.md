# Publish a documentation site

## Goal
Somewhere to send someone who wants to use sipx and is not going to read a Rust workspace to
find out how.

## Acceptance
- [x] A static site at `codewandler.github.io/sipx`, built from `docs/` rather than written
      twice — a second copy of the truth is a second copy to let rot.
- [x] Published by CI on push to `main`, not by hand.
- [x] The compliance table and the RFC roadmap are pages on it, generated by the same script
      that checks them.
- [x] The landing page answers "what is this and can it do what I need" above the fold, without
      a command in sight.
- [x] The README links to it, and it links back to the source.
- [x] Builds are reproducible locally with one command, so a change can be seen before it ships.

## Progress
- Done. mdBook with `src = "docs"`, so the site is the existing documentation rather than a copy
  of it. `SUMMARY.md` decides what is a page: compliance, the RFC roadmap, status, vision and
  the design records. Stories and specs stay in the repository — a spec is a contract for
  whoever implements it, not something to send a reader to.
- `./scripts/build-docs.sh` is the one command, and it **checks links**. That check is the part
  worth having: the site is built from a directory that also holds the internal docs, so a
  cross-reference from a published page into an unpublished one is a 404 that only appears once
  the site is live. It found eight on the first run — `roadmap.md` linked to seven design records
  and to the board. The designs are now published; the board points at GitHub.
- Published by CI on push to `main` through `actions/deploy-pages`, and *built* on pull requests
  too, so a broken link fails review rather than the deployed page.
- A logo: a crab holding a telephone handset, drawn for sipx rather than borrowed. Rust's mascot
  is a crab and so is this one, but the shapes are original and the handset is the part that
  makes it a telephony mark rather than a Rust one. It went through four passes — the first had
  the handset floating beside the shell rather than held, and the cord kept ending up behind the
  claw where it read as a smudge. Checked at 64 px, which is the size that actually decides
  whether a logo works.

## Notes
- The constraint that shapes it: an end user is not going to type a lot of commands. The site
  is for deciding whether sipx fits, and for reference once it does — not a tutorial that
  assumes a terminal is already open.
